02 / WORKLOAD

작업의 요구와
실행 상태를 함께.

자원을 요청한 작업이 어디에서 실행되는지, 무엇을 기다리는지 확인합니다. 워크로드를 기준으로 자원 운영의 맥락을 이어갑니다.

  • 팀 · 프로젝트별 작업 맥락
  • 요청 자원과 할당 상태 확인

03 / ALLOCATION

배치한 뒤에도,
운영은 계속되니까.

작업에 자원을 배치하는 순간에서 끝나지 않습니다. 사용 상태를 살펴보고, 남는 자원을 다시 풀로 연결하는 흐름을 보여줍니다.

  • GPU 할당과 회수 상태
  • 작업과 자원의 연결 관계

BEFORE YOU START

궁금한 점을
더 명확하게.

FRACTOS와 STRATOS는 어떻게 다른가요?+

FRACTOS는 GPU 자원과 워크로드의 운영을, STRATOS는 사용량과 예산·비용의 맥락을 담당합니다. 같은 자원 정보를 서로 다른 운영 관점에서 연결합니다.

어떤 기준으로 자원을 확인할 수 있나요?+

클러스터와 노드의 구조, GPU 상태, 연결된 워크로드를 기준으로 살펴봅니다. 팀과 프로젝트의 작업 맥락에서 자원 배치를 확인합니다.

전체 제품을 함께 도입해야 하나요?+

제품별 역할을 구분해 살펴볼 수 있습니다. 실제 도입 범위와 기존 자원 환경의 연동 방식은 환경을 확인한 뒤 정리합니다.
