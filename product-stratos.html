THE CHALLENGE / OUR APPROACH

얼마나 썼는지에서,
어디에 썼는지까지.

총사용량만으로는 팀의 운영을 설명하기 어렵습니다. 어떤 프로젝트가 자원을 사용했는지, 예산과 어떤 관계가 있는지. STRATOS는 사용의 기록을 관리의 기준으로 연결합니다.

03

WHAT STRATOS DOES01 — 03 / FEATURES

01 / METERING

사용의 기록을,
같은 기준으로.

자원을 사용한 시간과 대상을 확인하는 데서 시작합니다. 팀과 프로젝트별로 사용을 살펴볼 수 있도록 계측의 관점을 정리합니다.

  • 자원 사용량 계측
  • 팀 · 프로젝트별 사용 맥락
  • 기간을 기준으로 살펴보는 사용 추이

02 / BUDGET

예산을 숫자에서,
운영의 기준으로.

현재의 사용 상태를 예산과 함께 살펴봅니다. 사용과 한도의 관계를 확인하며 운영과 비용 사이의 판단을 돕습니다.

  • 팀별 예산 관리
  • 사용 상태와 예산 기준의 비교
  • 기간에 따른 사용 흐름 확인

03 / GOVERNANCE

누가, 어디에 썼는지.
배분의 맥락까지.

계측된 사용량을 바탕으로 정산과 비용 배분의 관점을 연결합니다. 조직에서 합의한 기준을 실제 사용의 기록과 함께 살펴봅니다.

  • 사용량 정산의 기준
  • 팀 · 프로젝트별 비용 배분 맥락
  • 설명 가능한 사용 기록

BEFORE YOU START

궁금한 점을
더 명확하게.

사용량은 어떤 단위로 살펴보나요?+

팀과 프로젝트, 계측 대상과 집계 기간을 기준으로 사용량을 살펴봅니다. 같은 기준에서 사용 추이와 예산의 관계를 확인하는 것이 출발점입니다.

GPU 할당도 STRATOS에서 하나요?+

GPU 자원과 워크로드 운영은 FRACTOS의 역할입니다. STRATOS는 사용량과 예산·비용의 관점에서 연결합니다.

비용 배분 기준은 어떻게 정하나요?+

실제 계측 대상, 집계 기간과 배분 기준은 조직의 운영 환경과 합의한 정책에 맞춰 정리합니다.
